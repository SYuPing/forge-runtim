Forge Runtime：Intent → Context Build

自上而下閱讀；右側只畫分支與併發。

已落地部分完成旁路／離開等待
01

RECEIVE

收到原始輸入。
固定往下。

入口旁路
  • Intent shortcut／missingAssets：留在 RECEIVE 等明確同意。
  • 缺知識檔：start_forge 後仍在 RECEIVE 等明確同意。
  • 缺 model／registry／解析失敗：start_forge fail-closed。
02

INTENT_UNDERSTANDING

判斷是否啟動。
等模型最多 10 秒。

分支
  • /grill-run：跳過分類，啟動 Forge
  • 其他 slash：離開 Forge
  • 已有 workflow：拒絕雙開
  • 無 model／registry、逾時／錯誤／無效輸出：start_forge fail-closed
  • passthrough：離開 Forge
03

LIGHT_DISCOVERY

只找候選檔與 metadata。
完成後進 Grill。

04

GRILL

逐輪查證，八次有效回答後進 checkpoint。
完成狀態：READY_FOR_DEEP。

條件
  • 第 8 次 → WAIT_USER(grill_checkpoint)
  • relevance 足夠 → DEEP_KNOWLEDGE_RETRIEVAL
  • 不足 → WAIT_USER(relevance_clarification)
checkpoint
  • continue_one → Grill；converge → 跳過 relevance
  • 0 個知識盲點 → 直接 Deep；最多 1 個回答 → 直接 Deep
  • cancel → 完整 cleanup → RECEIVE
05

WAIT_USER

流程停住等人，接收五種 payload kind。
正常路徑為 status-only，不送 transcript／displayOnly delivery。

等待契約
  • grill_confirmation
  • grill_checkpoint
  • relevance_clarification
  • deep_decision
  • deep_discovery_fallback
  • 只發布 UI status，無 transcript／displayOnly delivery
06

USER_CONFIRMED

接住人類回答，依 wait kind 分流。
等待 payload 不是 workflow state。

依 wait kind
  • grill_confirmation → Grill（同 snapshot）
  • grill_checkpoint 固定選項：continue_one
  • grill_checkpoint 固定選項：converge
  • grill_checkpoint 固定選項：cancel → cleanup → RECEIVE
  • relevance_clarification → Light → 新 snapshot → Grill
  • deep_decision → 原 Deep phase → follow-up
  • deep_discovery_fallback 可見確認 → KU＋human_premise
  • deep_discovery_fallback 可見取消 → cleanup → RECEIVE
  • fallback 舊「同意」僅 hidden typed 相容
07

DEEP_KNOWLEDGE_RETRIEVAL

深查允許來源。
完成進 KU；需要決定則等人。

PI parallel
  • PI 可平行多個 search
  • Forge call-ID barrier 等 all settled
mixed batch
  • mixed batch 依 call-ID 聚合
  • 完成 retryable reject；下一 completion-only batch 接受
identity
  • fresh identity 推進
  • stale identity terminate
discovery
  • 首次 needs_discovery → Light → settled restart
  • 再次 needs_discovery → WAIT_USER(deep_discovery_fallback)
needs_decision → WAIT_USER → 原 Deep phase
08

KNOWLEDGE_UNDERSTANDING

把 Evidence Package 固定成結論。
validator 通過進 Context；fail 留在本 phase。

Finding
  • Finding 必須有 evidence
  • human-premise-only Finding 須以「推論：」開頭
Spec Gap
  • Evidence Package 已在 production live
  • forge_deep_complete 尚未傳 verificationLevel／specGap／formalSpecReference
  • trusted formal-spec importer 未落地，spec_verified fail-closed
needs_decision → WAIT_USER → 原 Deep phase
09

CONTEXT_BUILD

目前只有狀態切換。
buildContextItems() 無 production caller，尚未接入。
