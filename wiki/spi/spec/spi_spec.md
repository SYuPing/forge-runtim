## HT8 MCU SPI 應用須知及範例

文件編號：AN0488TC

## 簡介

SPI (Serial Peripheral Interface)是一種同步、高速、全雙工的串行通訊總線，它是以主從方式 工作，這種模式通常由一個主設備和一個或多個從設備組成。SPI 常用在與外部設備如感測 器、快閃記憶體或 EEPROM記憶體等通訊。

本文分別由功能說明和應用注意事項，結合程式範例來介紹HT8 MCU SPI 應用方法。

## 功能說明

HT8 MCU 提供了獨立的 SPI、SIM、USIM 的三種 SPI 功能介面，下表列出三種介面主要差 異。

| 區別 | 獨立 SPI | SIM | USIM |
| --- | --- | --- | --- |
| 支援通訊協議 SPI |   | SPI、I2C | SPI、I2C、UART |
|   | SPI mode 選取 通過暫存器 SPIAC0 切換 SPI master mode or SPI slave mode | 通過暫存器 SIMC0 切換 SPI master mode or SPI slave mode | 通過暫存器 SIMC0 UMD 位元、SIM[2:0]位元選擇 SPI 模式 |

三種 SPI 介面支援通訊協議和選取方式會略有不同，但在應用上原理相似。下面藉由 SIM， 從 SPI 介面及特點、相關暫存器、SPI 通訊說明 3 個方面來介紹 SPI 功能。

## SPI 介面及特點

## 介面說明

SPI 是一個主從式同步串列資料傳輸介面，允許一個主機控制多個從機。通常 SPI 介面採用 四根腳位通訊，分別為：SDI、SDO、SCK和 SDI SDO SCK是串列時鐘線

## 特點介紹

SPI 功能具有以下特點。

- 1. 主從模式控制方式。

- 2. 同步傳輸數據。

- 3. 最低有效位元(LSB)先傳或最高有效位元(MSB)先傳的資料傳輸模式。

- 4. 傳輸完成旗標位元。

- 5. 時鐘源上升緣或下降緣有效。

## 暫存器介紹

SIM 結構的 SPI 介面有三個内部暫存器用於控制所有操作，其中有一個數據暫存器 SIMD、 兩個控制暫存器 SIMC0 和 SIMC2。具體說明可參考MCU 規格。

| 暫存器名稱 | 作用 |
| --- | --- |
| SIMD | 用於儲存發送和接收的數據 |
| SIMC0 | 用於控制致能/禁能功能和設定數據傳輸的時鐘頻率 |
| SIMC2 | 用於其它的控制功能如 LSB/MSB 選擇，寫衝突旗標位元等 |

## 應用注意事項

在應用HT8 MCU SPI 功能時，請注意以下事項。

## 片選腳位SCS

移位時，也可利用此腳位重新同步，當傳輸尚未完成時，主機將腳位拉高準位，則從機的 SIMICF 及 TRF 旗標會被設定為 1，進而進行同步。

因 HT8 MCU 實際應用環境不同，可能會出現無法使用SCS 時，可以使用主從機資料回傳進行比對或是隔幾筆資料中加入校驗碼來確定傳輸過程未發 生錯誤，但當發生資料錯誤或移位情形時，無法進行重新同步，因此提供兩種方式來解決不 使用SCS

- 1. CSEN禁能：如將 CSEN致能，而從機的SCS 位誤判情形，且無法重新同步，後續傳輸將產生一連串錯誤，故將 CSEN 禁能，讓從機 隨時保持準備接收值的狀態，且不受SCS

- 2. 外部腳位控制：使用一般 I/O 腳位替代SCS 透過不同腳位進行選擇傳輸對象，從機則可以判斷此腳位準位進行重啟 SPI 功能(可參考 本文後面 HT66FV140 的一般 I/O腳位替代SCS

- 註：1. 當 CSEN禁能時，將對應之腳位設定為 I/O 功能，可以防止空接所帶來的耗電問題。 2. 主機將腳位拉高準位後，需等待從機一段時間確保從機來得及重啟 SPI 功能。

## VDDIO 腳位使用說明

為了適應不同的週邊器件介面電壓需要，部分 HT8 MCU 提供了 VDDIO 腳位，可進行電壓 轉換(Level Shift)。例如：HT66FV140 Enhanced Voice 8-Bit Flash MCU需要工作在 5V 時，但外 接 SPI Flash 工作電壓卻為 3.3V。此時VDD可接 5V，VDDIO 可接 3.3V。這樣就解決了MCU 工作電壓與週邊電壓不匹配問題。可通過 PBS0 暫存器之 Bit 1~0 來配置VDDIO 管腳功能。 如下：

PBS01~PBS00：PB0 腳位功能選擇

00/01/10：PB0

11：VDDIO


該腳位作為VDDIO 時，相應的 I/O 功能及其上拉電阻都將禁能，Port C 的電源將由VDDIO 腳位提供。

註：詳細請參考HT66FV140 Enhanced Voice 8-Bit Flash MCU規格書。

## 其他事項

- 1. 主機控制的時鐘頻率要考慮從機接收的最快速率，例如：讀 SPI 介面的 Flash 時，要根 據 Flash 的最快速率來設定主機的時鐘，若選擇的是做為 SPI 從機，則其時鐘源由外部 主機控制。

- 2. 在微控制器處於空閒模式時，若 SPI 介面使用的時鐘源仍開啟，SPI 功能仍將繼續執行。

- 3. SPI 中斷來源於數據發送/接收完成(TRF=1)與數據傳輸未完成(SIMICF=1)，當中斷致能時， 可跳轉至相關 SIM 中斷向量副程式中執行。

## 範例 3 - 通過 SPI 存取外部 Flash
